# 解説

このクイズの出力は `・^・` です。一見すると顔文字 `・^・` だけが並んでいるように見えますが、すべてが意味のあるKotlinのコードになっています。

元のコードは1行で書かれた次の難読形です。

```kotlin
data object `・^・`;{`・^・`:`・^・`->(`・^・`)}(`・^・`)
```

実際に動く形に整えると、次のようになります。

```kotlin
data object `・^・`
fun main() {
    val r = { `・^・`: `・^・` -> (`・^・`) }(`・^・`)
    println(r)
}
```

ポイントは、Kotlinではバッククォート `` ` `` で囲むことで、記号を含む通常は使えない文字列も識別子として使える、という仕様です。ここではすべての箇所で `` `・^・` `` という同じ見た目の識別子を使い回しています。

## それぞれの要素

### `data object \`・^・\``

```kotlin
data object `・^・`
```

これは、バッククォートで囲んだ識別子 `・^・` を名前に持つ **data object**（シングルトン）を宣言しています。`object` はインスタンスがひとつだけ存在するシングルトンで、`data object` にするとデータクラス相当の便利なメソッド（`toString()` など）が自動生成されます。

ここで宣言した `` `・^・` `` は、

- そのシングルトンの**インスタンス**を指す名前
- 同時にそのインスタンスの**型名**

の両方として使えます。

### ラムダ `{ \`・^・\`: \`・^・\` -> (\`・^・\`) }`

```kotlin
{ `・^・`: `・^・` -> (`・^・`) }
```

これはラムダ式です。`->` の左側がパラメータ宣言、右側が本体です。

- パラメータ名: `` `・^・` ``
- パラメータの型: `` `・^・` ``（=さきほど宣言した data object の型）
- 本体: `(`・^・`)`（受け取った引数 `` `・^・` `` をそのまま返す。括弧は単なるグループ化）

つまり「`・^・` 型の `・^・` を受け取って、その `・^・` を返す」恒等関数です。すべて同じ見た目の識別子なのが難読たるゆえんです。

### 即時呼び出し `(\`・^・\`)`

```kotlin
{ ... }(`・^・`)
```

ラムダの直後に `(`・^・`)` と書くことで、そのラムダを即座に呼び出しています。渡している引数 `` `・^・` `` は data object のインスタンスです。よってラムダはこのインスタンスをそのまま返します。

## なぜ `・^・` と出力されるのか

`data object` は `toString()` が自動生成され、その戻り値は **オブジェクトの単純名（simple name）** になります。今回の単純名は `` `・^・` ``、すなわち文字列 `"・^・"` です。

ラムダが返した data object インスタンスを `println` に渡すと `toString()` が呼ばれ、`・^・` が出力されます。

見た目はすべて顔文字 `・^・` でありながら、

1. data object の宣言
2. 型注釈付きラムダ（恒等関数）
3. 即時呼び出し
4. data object の自動 `toString()`

という仕組みが噛み合って動く、というのがこのクイズの面白さです。
