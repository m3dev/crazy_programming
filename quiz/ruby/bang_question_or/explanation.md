# 解説

```ruby
!?|||?|
```

このコードの実行結果は `"|"` です。

## ポイント

縦棒 `|` が連続していて読みにくいですが、鍵は `?` から始まる文字リテラルです。

### `?|` は文字リテラル

Rubyでは `?x` という記法で **1文字の文字列リテラル** を書けます。たとえば `?a` は `"a"` です。したがって `?|` は文字列 `"|"` です。

### トークン分解

この式は次のように区切られます。

```ruby
!?| || ?|
```

- `!?|` … `!(?|)` すなわち `!"|"`
- `||` … 論理和
- `?|` … 文字列 `"|"`

### 評価

```ruby
!"|"            # => false （nil と false 以外はすべて真なので、"|" を否定すると false）
false || "|"    # => "|"   （左が偽なので右の値を返す）
```

`||` は左辺が真ならその値を、偽なら右辺の値を返す演算子です。左辺 `!"|"` は `false` なので、右辺の `"|"` がそのまま結果になります。

`?|` という文字リテラルと、`!` `||` の優先順位を見抜けるかを問う問題でした。
