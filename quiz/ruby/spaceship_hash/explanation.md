# 解説

```ruby
{?<=>{}}<=>{?<=>{}}
```

このコードの実行結果は `0` です。

## ポイント

`<=>`（宇宙船演算子）と `<`、そして文字リテラルが絡み合っています。

### `?<` は文字リテラル

`?<` は文字列 `"<"` です。これを踏まえると、`{?<=>{}}` は次のように読めます。

```ruby
{ ?< => {} }
# = { "<" => {} }
```

つまりキー `"<"`、値が空ハッシュ `{}` のハッシュ `{"<"=>{}}` です。`?<` が文字リテラルとして消費されるため、その直後の `=>` がハッシュの矢印として機能します。

### 全体の構造

すると全体は、同じ内容のハッシュ2つを宇宙船演算子 `<=>` で比較する式になります。

```ruby
{"<"=>{}} <=> {"<"=>{}}
```

### `Hash#<=>` の結果

`Hash` の `<=>` は、2つのハッシュが等しいとき `0` を返します（包含関係に応じて `-1` や `1`、比較不能なら `nil` を返すこともあります）。

ここでは左右がまったく同じ内容のハッシュなので、結果は `0` になります。

```ruby
{?<=>{}}           # => {"<"=>{}}
{?<=>{}}<=>{?<=>{}} # => 0
```

`?<` を「`?` と `<` の2トークン」と読み違えないか、また同値ハッシュの `<=>` が `0` になることを知っているかを問う問題でした。
