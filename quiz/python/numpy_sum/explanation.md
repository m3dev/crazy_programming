# 解説

問題を丁寧に書くと何やらsumの引数が2つあることが見えてきます。

```python
sum( [sum:=-1], np.sum([sum],sum) )
```

標準関数のsum関数の第2引数はstart値です。

```python
>>> sum( [1, 2, 3], 10 )  # 10+1+2+3で16となる
16
```

start引数のデフォルト値は数値の0です。
start引数に数値以外を入れる事でlistのflatten等が実現できます。

```python
>>> sum( [[1, 2], [3, 4]], [] )  # []+[1,2]+[3,4]になりlistのaddにより[1,2,3,4]
[1,2,3,4]
```

もう1つ、標準関数のsumではなくnumpy.sumが利用されています。
こちらのsumの第2引数は行列を現すaxisに当たります。

```python
>>> x = np.arange(4).reshape(2, 2)
>>> print(x)
[[0 1]
 [2 3]]

>>> print(np.sum(x, axis=0))  # 縦方向へのsum
[2 4]

>>> print(np.sum(x, axis=1))  # 横方向へのsum
[1 5]
```

そして、問題の標準関数sumの中の第一引数の中ではsumに別の値が代入されています。
Assignment Expressionsによりsumには-1がはいる事を加味し問題を簡略化したコードを示します。

```python
sum( [sum:=-1], np.sum([sum],sum) )
sum( [-1], np.sum([-1], -1) )
```

実質的に-1をstart値とした[-1]のsumと言えるので答えは以下のようになります。

```python
>>> sum( [-1], -1 )
-2
```

標準関数のsumとnumpy.sumの違いを使った問題でした。
sumを変数として値を代入してしまっているため、2度同じREPL上で実行できない事から、SNS上でも疑問の声が多い問題の1つでした。
綺麗に分解してみると知識の問題になる系統の問題でもあります。
