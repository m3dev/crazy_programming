# 解説

大量の括弧に圧倒されますが、Empty Tuple Keyの「括弧増し増し」版です。
ポイントは、丸括弧`()`が「グループ化」と「空タプル」のどちらにもなるという点です。

中身の無い`()`は空タプルです。そして、その空タプルをさらに括弧で囲んでも、
それは単なるグループ化であって中身は変わらず、結局また同じ空タプルになります。

```python
>>> ()
()
>>> (())
()
>>> ((()))
()
>>> (((())))
()
```

カンマが無い限り、外側の括弧はタプルを新しく作らずグループ化として扱われるため、
何重に重ねても`()`（空タプル）のままです。

これを踏まえて問題を読み替えると、

```python
{((())):(())}[(((())))]
```

は、キー`()`・値`()`の辞書を作り、キー`()`で参照しているだけになります。

```python
>>> {():()}[()]
()

>>> {((())):(())}[(((())))]
()
```

見た目の複雑さに反して、実体はEmpty Tuple Keyと同じ`()`を返す問題でした。
