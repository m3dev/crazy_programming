# 解説

この問題はf-stringを入れ子にし、さらに`=`デバッグ指定を重ねています。

まずf-stringの`=`デバッグは「式のテキスト」と「その評価結果のrepr」を並べて表示する機能です。

```python
>>> f"{'a'+'b'=}"
"'a'+'b'='ab'"
```

式テキスト`'a'+'b'`と、結果`'ab'`のrepr`'ab'`が並んで`'a'+'b'='ab'`になります。同様に次のようになります。

```python
>>> f"{'c'+'d'=}"
"'c'+'d'='cd'"
```

問題のコードを外側と内側に分けます。

```python
f"""{  f"{'a'+'b'=}"+f"{'c'+'d'=}"  =}"""
```

内側の式は2つのf-stringの文字列連結です。それぞれの結果を連結すると次の文字列になります。

```python
>>> f"{'a'+'b'=}" + f"{'c'+'d'=}"
"'a'+'b'='ab''c'+'d'='cd'"
```

外側のf-stringでも`=`デバッグが使われているので、「内側の式のテキスト」+「`=`」+「内側の結果のrepr」が出力されます。
内側の式テキストは`f"{'a'+'b'=}"+f"{'c'+'d'=}"`、結果は上の文字列で、そのreprはクォートで囲まれた`"'a'+'b'='ab''c'+'d'='cd'"`です。

```python
>>> f"""{f"{'a'+'b'=}"+f"{'c'+'d'=}"=}"""
'f"{\'a\'+\'b\'=}"+f"{\'c\'+\'d\'=}"="\'a\'+\'b\'=\'ab\'\'c\'+\'d\'=\'cd\'"'
```

`print`した出力は以下になります。

```
f"{'a'+'b'=}"+f"{'c'+'d'=}"="'a'+'b'='ab''c'+'d'='cd'"
```

外側の`=`が内側の結果をreprで囲むため、内側の式テキストと結果が二重に並び、イコールとクォートが入り乱れて見える問題でした。
