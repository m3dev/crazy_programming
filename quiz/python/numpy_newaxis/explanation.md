# 解説

numpyの配列インデックスに現れる`None`と`...`の意味を問う問題です。

まず`x`は`(2, 2)`形の、要素がすべて1.0の配列です。

```python
>>> import numpy as np
>>> x = np.ones((2, 2))
>>> x.shape
(2, 2)
```

ここで`x[(None, ..., None)]`のインデックスを分解します。

numpyのインデックス内に書いた`None`は`np.newaxis`と同じ意味で、その位置に長さ1の新しい軸を挿入します。

```python
>>> x[None].shape
(1, 2, 2)
>>> x[..., None].shape
(2, 2, 1)
```

`...`（`Ellipsis`）は「残りの全次元」を表すプレースホルダで、ここでは元の`(2, 2)`の2軸に対応します。

したがって`(None, ..., None)`は、

- 先頭に長さ1の軸を1つ追加
- `...`が元の`(2, 2)`を維持
- 末尾に長さ1の軸を1つ追加

となり、shapeは`(2, 2)`から`(1, 2, 2, 1)`へ変形されます。

```python
>>> x[(None, ..., None)].shape
(1, 2, 2, 1)
>>> print(x[(None, ..., None)])
[[[[1.]
   [1.]]

  [[1.]
   [1.]]]]
```

インデックスの中の`None`が`newaxis`であると気付けるかが肝の問題でした。
