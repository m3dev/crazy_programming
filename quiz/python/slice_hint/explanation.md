# 解説

`;`記号は改行なので実質的に以下のような3行のコードです。

```python
_:...=[]
_[:]:...=f'{f"{[...][::][0]}"::^0}'
print(_)
```

Ellipsisは省略表記のオブジェクトです。

```python
>>> print(...)
Ellipsis
```

numpyなどではよくスライス時に省略表記として使われます。

```python
>>> import numpy
>>> x = numpy.array([[1, 2], [3, 4]])
>>> print(x[1, ...])
[3, 4]
```

代入演算子の前に付いたEllipsis(...)はType Hintの扱いを受けています。
Type Hintには式や値も記載することができます。
Type Hintの型と代入値が合っていなくても無視される辺りがPythonらしいです。

```python
>>> x: int = 1
>>> x: 10 = 2
>>> x: "s" = 1
>>> _: ... = []
>>> print(_)
[]
```

問題の2行目に値する式もType Hintを除いて記載してみるとシンプルです。
何らかのf-stringを使った文字列を代入しているようです。

```python
_[:]=f'{f"{[...][::][0]}"::^0}'
```

f-stringが2重に掛かっているので評価順を考えまず一番内側を見てみます。
配列のスライスを上手く使っているように見えますが0番目を取り出しているだけです。
つまりEllipsis(...)を文字列化しているだけになります。

```python
>>> f"{[...][::][0]}"
"Ellipsis"
```

外側のf-stringで使われている記法は文字列の中央揃えです。
Ellipsisを0個の":"で中央揃えしているので結果は"Ellipsis"です。

```python
>>> x = 10

>>> print(f"{x:@^6}")
@@@10@@@

>>> print(f"{x::^6}")
:::10:::

>>> f'{"Ellipsis"::^0}'
"Ellipsis"
```

スライス配列へ文字列がそれぞれ代入される形になります。

```python
>>> x = []
>>> x[:] = "test"
>>> print(x)
['t', 'e', 's', 't']
```

故に2行目の結果は"Ellipsis"が分割された配列です。

```python
>>> _[:]:...=f'{f"{[...][::][0]}"::^0}'
>>> print(_)
['E', 'l', 'l', 'i', 'p', 's', 'i', 's']
```

3行目は標準出力のみとなるため、この問題の実行結果は以下の通りです。

```python
>>> _:...=[];_[:]:...=f'{f"{[...][::][0]}"::^0}';_
['E', 'l', 'l', 'i', 'p', 's', 'i', 's']
```

Slice、Assignment Expressions、Ellipsis、f-stringとあらゆる点が使われる構文を使った問題でした。
