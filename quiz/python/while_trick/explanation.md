# 解説

アンダーバーは、REPL上では前回の実行の出力という意味です。
また変数_として扱う事もできます。

```python
>>> 1
1
>>> print(_)
1

>>> _ = 2
>>> print(_)
2
```

REPLでは、`;`を挟むと実質的な改行になります。

```python
>>> x=2;print(x)
2
```

上記の事を加味して、問題の2行を改行ありの問題として書き換えてみます。
REPL上で最後の実行結果は、標準出力なのでprint文に変更しています。

```python
x = [1, 2, 3, 4]
while x:
    x, *x = x
    print(x)
```

ここで、配列とunpackへの代入を理解する必要があります。
`*`以降の変数には配列indexへのunpackの結果が入ります。

```python
>>> a, *b = [1, 2, 3, 4]
>>> print(a)
1
>>> print(b)
[2, 3, 4]
```

上記のことが分かるとwhile文は以下のように繰り返されることが分かります。
配列の後半部分を取得し、変数_に入った配列が空になった時点で終了します。

```python
>>> [1,2,3,4]
[1, 2, 3, 4]

>>> while _:_,*_=_;_
[2, 3, 4]
[3, 4]
[4]
[]
```

この問題は、実はPythonのunpack処理の特性を利用した問題でした。
また、アンダーバーの活用は難読化でも非常に良く使えるテクニックですので、覚えておくと良いです
