# 解説

Pythonにはf-stringやformatメソッド等、テキストフォーマットに関する構文がいくつか存在します。
この問題ではf-stringの特性を取り扱っています。
まず、f-stringにより文字列に値を入れられます。

```python
>>> x = 10
>>> print(f"xの値は{x}です")
"xの値は10です"
```

イコール演算子を使う事で表記を工夫できます。

```python
>>> print(f"{x=}です")
"x=10です"
```

文字列`=`は文字列`=`である事を表現すると、以下のような式になります。

```python
>>> f"{'='=}"
"'='='='"
```

上記を２つ繋げると答えが見えてきます。

```python
>>> "'='='='" + '=' + "'='='='"
"'='='='='='='='"

>>> f"{'='=}={'='=}"
"'='='='='='='='"
```

f-stringを上手く使って、問題文上と解答上で同様にイコールを繋げることができました。
答えを見て2度面白いタイプの問題です。
