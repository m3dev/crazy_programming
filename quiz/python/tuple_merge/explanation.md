# 解説

この問題を解くには、2つのポイントを知っておく必要があります。
それぞれのポイントを抑えながら、問題を紐解いていきます

```python
(((0)|1)|2)|3
```

tupleの内容が1つの時は評価結果はtupleではなくなります。

```python
>>> print((1, 2))
(1, 2)

>>> print((1))
1
```

`|`は論理和(OR)を扱う演算子です。
00と01のORは1です。

```python
print(0|1)
1
```

01と10のORは11、11と11のORは11です。

```python
>>> print(1|2)
3

>>> print(3|3)
3
```

`(((0)|1)|2)|3`を内側から紐解いていくと`3`になる、という問題でした。
