# 解説

なにかの文字列をint値に変換しています。中身の文字列を細かく見ていきます。

文字列のプレースホルダによるフォーマットは%演算子でも可。
`s"{1}"や"{}".format(1)` と同じです。

```python
>>> print("%s" % 1)
"1"
```

%演算子は複数使って繋げる事が可能です。
プレースホルダのフォーマットは前から処理されます。

以下は%%%sが%sに置換され、その後に%sが1に置換される例です。

```python
>>> print("%%%s" % "s" % 1)
"1"
```

先の問題のアンダーバーや接頭辞を考え、問題の文字列部分を置換します。

```python
"%s_0%%s" % 0 % 10
```

先頭の%s演算子を置換します。

```python
"0_0%s" % 10
```

次のプレースホルダを置換します。
アンダーバーは可読性のための記述に当たるので省略して考えます。

```python
>>> int("0_010")
10
```

文字列のプレースホルダを上手く使いながら、Pythonの数値の特性に活かしていく問題でした。
難読クイズの応用が聞きやすいナレッジが詰まっています。
