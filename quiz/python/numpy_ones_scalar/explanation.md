# 解説

`np.ones`は、指定したshape（形）の、要素がすべて1.0の配列を作る関数です。

```python
>>> import numpy as np
>>> np.ones(3)
array([1., 1., 1.])
>>> np.ones((2, 2))
array([[1., 1.],
       [1., 1.]])
```

この問題では`np.ones(())`と、shapeに空タプル`()`を渡しています。
shapeのタプルの長さが配列の次元数（軸の数）に対応するため、空タプルは「0次元の配列」を意味します。

0次元配列はスカラーを1つだけ包んだ配列で、要素数は1、値はここでは1.0です。

```python
>>> a = np.ones(())
>>> a.shape
()
>>> a.ndim
0
>>> a
array(1.)
```

表示も角括弧の付かない`array(1.)`になります。

```python
>>> print(np.ones(()))
1.0
```

なお`print`で表示すると`1.0`ですが、`array(1.)`という0次元配列が作られているのがポイントです。
`()`をshapeに渡すと0次元になる、という挙動を知っているかが問われる問題でした。
