# 解説

一見すると記号の羅列に見えますが、`()`の正体が分かれば一気にほどけます。
Pythonにおいて、中身の無い丸括弧`()`は空のタプルを表します。

```python
>>> ()
()
>>> type(())
<class 'tuple'>
```

問題を分解すると、まず`{():()}`の部分はdict（辞書）のリテラルです。
キーが`()`、値が`()`の、要素を1つだけ持つ辞書になります。

```python
>>> {():()}
{(): ()}
```

そして末尾の`[()]`は、その辞書に対するキー`()`での参照です。

```python
>>> d = {():()}
>>> d[()]
()
```

キー`()`に対応する値`()`、すなわち空タプルが取り出されます。

```python
>>> {():()}[()]
()
```

空タプルがキー・値・参照のすべてに使われているため、記号だけを見ると混乱しますが、
落ち着いて`()`を空タプルと読み替えれば素直な辞書アクセスだと分かる問題でした。
