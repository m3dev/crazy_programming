# 解説

この問題は `Walrus Default` の対比版です。見た目はよく似ていますが、引数の渡し方が違います。

```python
((lambda _=(_:=()):_)(_=(_:=())))
```

lambdaは`_`という引数を受け取り、それをそのまま返す関数です。
ポイントは呼び出し側の `_=(_:=())` です。これは**キーワード引数** `_=...` として渡されています。
右辺の `_:=()` はセイウチ演算子で、変数`_`に空タプル`()`を代入しつつ値`()`を返します。

```python
>>> (_ := ())
()
```

つまりキーワード引数 `_` には`()`が渡り、lambdaはそれを返します。

```python
>>> ((lambda _=(_:=()):_)(_=(_:=())))
()
```

答えは`()`です。

位置引数版（`Walrus Default`）では `(_:=())` のように渡し、キーワード引数版（本問）では `(_=(_:=()))` のように渡します。
`_=...` がキーワード引数なのか、それともセイウチ代入なのか一見で見分けがつかないのに、どちらも結果は`()`になる、という対比が面白い問題でした。
