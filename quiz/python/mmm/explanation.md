# 解説

リストのスライス、ポインタを扱った問題です。

```python
*M,M=[*"123"];"M"+M
```

文字列のポインタをリストとして評価すると分割されます。

```python
>>> print([*"123"])
["1", "2", "3"]
```

Pythonでは広く`*`が可変性を表します。
`*x`, `y`に代入するという事は可変な`x`と1つの`y`に値を代入するという事です。

```python
>>> *x, y = [1, 2, 3]
>>> print(x)
[1, 2]
>>> print(y)
3
```

上記を考慮すると問題の前半は前から評価していきMに3が入ります。

```python
>>> *M,M=[*"123"]
>>> print(M)
"3"
```

問題後半でM3が完成します。

```python
>>> print("M"+"3")
"M3"
```

`*M,M=[*"123"];"M"+M`は`"M3"`でした。
メタ読みしないで考えて下さいね！
