# 解説

エムスリーらしい文字列から始まる問題です。

```python
'IAMM3'[(x:=-~(1==1))::x]
```

Pythonのリストのスライスの仕様を知っていれば、問題を紐解くことで正答できます。

リストは`[始端:終端:間隔]`でスライスできます。
省略した場合は端まで間隔1になります。

```python
>>> print([0,1,2,3,4,5][1:3])
[1, 2]

>>> print([0,1,2,3,4,5][1:6:2])
[1, 3, 5]

>>> print([0,1,2,3,4,5][3::])
[3, 4, 5]
```

始端はチルダ(`~`)によるbool値のNOTです。
再度登場、実質的に`~x`は`-(x+1)`です。

```python
>>> print(-~(1==1))
2
```

セイウチ演算子は変数への代入と共に代入結果を返します。
結果的に問題は以下のように読めます。

```python
>>> print('IAMM3'[2::2])
"M3"
```

という訳で、答えは`"M3"`でした。

Pythonのリストのスライスは、間隔を良い感じに扱えることから、Code Golf等でもよく用いられます。
こうすると始点操作で2つの文字列を扱えます。

```python
>>> print("FBiuzzzz"[0::2])
"Fizz"

>>> print("FBiuzzzz"[1::2])
"Buzz"
```

つまり複数の条件分岐を空白いらずで短く扱えます。

```python
>>> x = 0
>>> print("FBiuzzzz"[x>0::2])
"Fizz"

>>> x = 1
>>> print("FBiuzzzz"[x>0::2])
"Buzz"
```

これらは実質以下と同じです。

```python
>>> print("Buzz" if x > 0 else "Fizz")
"Buzz"
```

こういったテクニックは実用的とは言えませんが、知っておくと便利かもしれない仕様があります。
