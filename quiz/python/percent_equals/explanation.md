# 解説

この問題はf-stringの`=`デバッグ指定と、古い`%`フォーマットを組み合わせています。

まず、f-stringの`=`は「式のテキスト」と「その評価結果のrepr」を並べて表示する機能です。

```python
>>> x = 10
>>> f"{x=}"
'x=10'
```

次に`%`演算子による文字列フォーマットを見ます。`'%s' % '='`は`%s`に`=`を埋め込むので`'='`になります。

```python
>>> '%s' % '='
'='
```

これを`=`デバッグの中に入れると、表示は「式テキスト`'%s'%'='`」+「`=`」+「結果のrepr`'='`」となります。

```python
>>> f"{'%s'%'='=}"
"'%s'%'='='='"
```

つまり出力は以下です。

```python
'%s'%'='='='
```

式テキストの中にも`=`が含まれ、結果のreprにも`=`が現れるため、イコールが連なって見える混乱を生む問題でした。
