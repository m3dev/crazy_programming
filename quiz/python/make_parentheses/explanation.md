# 解説

記号のみで作られた問題です。

```python
();((((_,_))))
```

この問題を解くには、Pythonのインタプリタの挙動を知っている必要があります。
アンダーバーはインタプリタ上では前回の実行の出力という意味です。

```python
>>> 1
1

>>> print(_)
1
```

括弧をいくつ繋げても中身が1つではtupleとして成立しません。

```python
>>> (((((1)))))
1
```

先に括弧が評価された後にアンダーバーが評価されます。

```python
>>> ()
()

>>> ((((_,_))))
((), ())
```

というわけで、答えは`((), ())`でした。
