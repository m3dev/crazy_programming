# 解説

numpy.zerosは0埋めされたarrayを生成するメソッドです。

```python
>>> import numpy as np
>>> np.zeros((2,2))
array([[0., 0.],
       [0., 0.]])
```

問題の前半はAssignment Expressionsを理解していると紐解けます。
変数_に1を代入しながら、1x1の0埋めされたarrayを生成しています。

```python
>>> np.zeros(( (_:=1), _ ))  # 先に前方のAssignment Expressionsが評価される
array([[0.]])

>>> print(_)
1
```

問題後半部を見やすくするため、変数_を数値に置き換えて見てみます。

```python
np.zeros((1,1)) [[(((0,),),)],(...)]
```

ここではtupleの特性を理解する必要があります。
tupleのように書いても1つの要素だった場合評価時にtupleでなくなります。
カンマを付けておくとtupleになります。

```python
>>> (1, 2)
(1, 2)

>>> (1)
1

>>> (1, )
(1, )
```

問題後半部にある括弧とカンマは評価後以下のようになることがわかります。

```python
np.zeros((1,1)) [[(((0)))], ...]
```

Ellipsisが省略記号ですので、特に意味はなく無視できます。

```python
np.zeros((1,1)) [[(((0)))]]
```

ここでnumpyの面白い仕様を扱います。
numpyはindexの指定と配列の拡張が同じ構文で行えてます。

```python
>>> np.zeros((1,1))
array([[0.]])

>>> np.zeros((1,1))[0]
array([0.])

>>> np.zeros((1,1))[[0]]
array([[0.]])

>>> np.zeros((1,1))[[[0]]]
array([[[0.]]])

>>> np.zeros((1,1))[[[[0]]]]
array([[[[0.]]]])

>>> np.zeros((1,1))[[[(0,)]]]
array([[[[0.]]]])
```

上記の配列次元を拡張する仕様を鑑みて再度問題を見てみると答えが分かります。

```python
>>> np.zeros((1,1)) [[(((0,),),)]]
array([[[[[0.]]]]])
```
