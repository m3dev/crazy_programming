# 解説

少しずつ分解しながら見ていきます。
アンダーバーによるAssignment Expressionsが難読化するために入っているので置換します。

```python
 ().__iter__().__class__.__name__[_:=-2]+[].__class__.__name__[_]
↓
().__iter__().__class__.__name__[-2] + [].__class__.__name__[-2]
```

分かりやすさのため、式の後半についてまず考えます。
Pythonはスーパークラスに__class__や__name__が定義されています。
`if __name__ == "__main__"` のような構文を見たことある方もいるでしょう。
`list`の`__class__.__name__`はその名前の通り`list`です。

```python
>>> [].__class__.__name__
'list'
```

後半はテキストの中から1文字取り出しているだけである事がわかります。

```python
>>> 'list'[-2]
's'
```

同じロジックで前半も見てみます。
`().__iter__`はtupleのiteratorを返すメソッドです。

```python
>>> ().__iter__().__class__.__name__
'tuple_iterator'
```

前半も後半同様にテキストの中から1文字取り出しているだけです。

```python
>>> 'tuple_iterator'[-2]
'o'
```

なのでこの問題は２文字を繋げて解答が出ます。

```python
>>> ().__iter__().__class__.__name__[-2] + [].__class__.__name__[-2]
'os'
```

"os"という文字を出すためだけに、上記のようなコードを書いたら絶対にプロダクトには入らないでしょう。
しかしながら、こういった手法が攻撃に使われたりする事例もあります。
難読化を学ぶ事は、こういった細かな仕様を学び、いざという時に対応する技術力を付ける方法でもあります。
