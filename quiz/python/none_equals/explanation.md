# 解説

これはf-stringのデバッグ用記法を使った問題です。
f-stringの`{}`内の式の末尾に`=`を付けると、「式のテキスト＝その値」の形で展開されます。

```python
>>> x = 10
>>> f"{x=}"
'x=10'
```

この記法を`None`に対して使うと、式のテキスト`None`と、その値`None`が`=`でつながれます。

```python
>>> f"{None=}"
'None=None'
```

問題の式`f"{None=}={None=}"`は、この`{None=}`を2つ並べ、その間にリテラルの`=`を1つ挟んだものです。
それぞれを置き換えると以下のようになります。

```python
>>> 'None=None' + '=' + 'None=None'
'None=None=None=None'

>>> f"{None=}={None=}"
'None=None=None=None'
```

`=`が等価演算子なのかf-stringのデバッグ記号なのか、リテラルの区切りなのかが混ざって見えるのがポイントです。
Equals問題の`None`版で、答えを見てもう一度楽しめるタイプの問題でした。
