# 解説

この問題はセイウチ演算子（代入式 `:=`）とlambdaのデフォルト引数を組み合わせています。

まずセイウチ演算子は「代入しつつその値を返す」式です。

```python
>>> (_ := ())
()
```

`_ := ()`は変数`_`に空タプル`()`を代入し、式としても`()`を返します。

問題のlambdaを見ます。

```python
(lambda _=(_:=()):_)(_:=())
```

lambdaは`_`という引数を1つ受け取り、それをそのまま返すだけの関数です。
デフォルト引数 `_=(_:=())` も評価され`()`になりますが、呼び出し側で位置引数 `_:=()` を渡しているので、デフォルト値は使われず上書きされます。

```python
>>> (lambda _=(_:=()):_)(_:=())
()
```

渡された引数`()`がそのまま返るので、答えは`()`です。
セイウチ演算子・デフォルト引数・位置引数が同じ`_`という名前で絡み合い、何が渡るのか分かりにくくする問題でした。
