# 解説

f-stringのデバッグ記法（末尾の`=`）が入れ子になった問題です。
まず`...`は`Ellipsis`というシングルトンオブジェクトのリテラルです。

```python
>>> ...
Ellipsis
```

内側のf-string`f'{...=}'`を見ます。
デバッグ記法により「式のテキスト`...`」＋「`=`」＋「値`Ellipsis`」が連結され、文字列`'...=Ellipsis'`になります。

```python
>>> f'{...=}'
'...=Ellipsis'
>>> len(f'{...=}')
12
```

`...=Ellipsis`は`.`が3つ、`=`が1つ、`Ellipsis`が8文字で、合計12文字です。

次に外側のf-string`f"{len(f'{...=}')=}"`を見ます。
こちらもデバッグ記法なので、「式のテキスト`len(f'{...=}')`」＋「`=`」＋「値`12`」が連結されます。

```python
>>> f"{len(f'{...=}')=}"
"len(f'{...=}')=12"
```

内側の評価結果（12）と、外側に表示される式テキストがそのまま見えるので、
入れ子のf-stringと評価順序を追えるかが肝でした。
