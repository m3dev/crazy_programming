# 解説

長い文字列置換を扱う問題です。

```python
"%%%s%%%%%%%%%%%%ss"%"d"%1%"%"%()%"2"
```

文字列のプレースホルダによるフォーマットは`%`演算子でも可です。
`s"{1}"`や`"{}".format(1)`と同じです。

```python
>>> print("%s" % 1)
"1"
```

`%`プレースホルダを使う時に文字列としての`%`は`%%`と表現します。

```python
>>> print("%d%%" % 100)
"100%"
```

`%`演算子を複数使って繋げる事が可能です。
プレースホルダのフォーマットは前から処理されます。
以下は`%%%s`が`%s`に置換され、その後に`%s`が`1`に置換される例です。

```python
>>> print("%%%s" % "s" % 1)
"1"
```

tupleやdictで複数のプレースホルダをまとめて扱えます。
空のtupleを渡した場合は何も変換されません。

```python
>>> print("%s%d" % (1,2))
"12"

>>> print("1" % ())
"1"
```

上記の点を利用して問題を前から実行して見ていきます。
最初の`%`演算子でいくつかの`%%`が`%`に、`%s`が`d`に置換されます。

```python
>>> print("%%%s%%%%%%%%%%%%ss" % "d")
"%d%%%%%%ss"
```

2つ目の`%`演算子で先頭に`1`が入ります。

```python
>>> print("%d%%%%%%ss" % 1)
"1%%%ss"
```

3つ目の`%`演算子で`%s`が`%`に置換されます。

```python
>>> print("1%%%ss" % "%")
"1%%s"
```

4つ目の`%`演算子では空のtupleが渡されているので何も置換されません。
よって`%%`が`%`になるだけです。

```python
>>> print("1%%s" % ())
"1%s"
```

最後の`%`演算子では素直に`2`が入ります。

```python
>>> print("1%s" % 2)
"12"
```

というわけで、`"%%%s%%%%%%%%%%%%ss"%"d"%1%"%"%()%"2"`は`12`でした。
