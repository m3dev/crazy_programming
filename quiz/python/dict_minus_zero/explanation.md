# 解説

この問題はPythonの数値リテラル表記と、dictのキー衝突を扱っています。

まずキーと値に使われている数値リテラルを読み解きます。Pythonでは数字の区切りにアンダースコア`_`が使え、`.0`や`00`のような書き方も許されます。

```python
>>> -.0_0
-0.0
>>> 00
0
>>> .0
0.0
>>> 00_0
0
>>> -0
0
```

問題のdictを整理すると、以下の3つのキーと値のペアになります。

```python
{-0.0: 0, 0: 0.0, 0.0: 0}
```

ここで重要なのは、Pythonのdictでは `0 == 0.0 == -0.0` がすべて等しく、ハッシュも同じため、これらは**同一のキー**として扱われる点です。

```python
>>> 0 == 0.0 == -0.0
True
>>> hash(0) == hash(0.0) == hash(-0.0)
True
```

そのため3つのペアは同じキーに次々と書き込まれます。
キーは最初に登場した`-0.0`が保持され、値は後から書かれたもので上書きされていき、最後の`-0`（intの`0`）が残ります。

```python
>>> {-.0_0:00_0,00:.0,.0:-0}
{-0.0: 0}
```

答えは`{-0.0: 0}`です。
見た目は0だらけですが、キーの同一性と上書きの順序を理解しているかが問われる問題でした。
