# 解説

4つのキーを持つように見える辞書ですが、出力は2要素になります。
辞書のキーは「`==`が真で、かつ`hash`値が等しい」ものを同一のキーとして扱います。

Pythonでは`bool`は`int`のサブクラスであり、`True`は`1`と等価です。
さらに整数`1`と浮動小数点`1.0`も等価で、これらのhash値はすべて一致します。

```python
>>> True == 1 == 1.0
True
>>> hash(True) == hash(1) == hash(1.0)
True
```

そのため`True`・`1`・`1.0`はすべて同じキーに衝突します。
辞書では、キーの実体（オブジェクト）は最初に挿入されたものが保持され、値は後から代入されたもので上書きされます。

```python
>>> d = {}
>>> d[True] = 'bool'   # キーは True として作られる
>>> d[1] = 'int'       # 同じキー、値だけ上書き
>>> d[1.0] = 'float'   # さらに値だけ上書き
>>> d
{True: 'float'}
```

一方、文字列`'1'`は数値とは等価でも同一hashでもないため、別のキーとして残ります。

```python
>>> {'1':'str', True:'bool', 1:'int', 1.0:'float'}
{'1': 'str', True: 'float'}
```

キーの表示は最初の`True`、値は最後の`'float'`が残るのがポイントでした。
