# 解説

Twitter全盛期に人気だったあの顔文字を模したクイズです。

```python
_(:3」∠)_
ー=≡Σ(   ε:) [＿＿]
```

1行目、`3J /2`は型ヒントで意味のないコードです。
絵文字っぽくするためだけに使われています。

```python
>>> _C=3
>>> print(_C)
3

>>> _C:3J /2=3
>>> print(_C)
3
```

2行目の`~`はビット演算における反転(NOT)です。
上の桁が0埋めされている前提でNOTを返します。
`~x`は`-(x+1)`と等価です(補数表現の詳しい話を除けば)。

```python
>>> print(~1)
-2
```

2行目の`_C`を`3`に置き換えると2行目前半部分は非常にシンプルです。

```python
>>> print(-~-(3-8))
6
```

後半部分、配列に正の数字を掛けると増えます。

```python
>>> print(6*["布団"])
["布団", "布団", "布団", "布団", "布団", "布団"]
```

という訳で、この顔文字問題の答えは`["布団", "布団", "布団", "布団", "布団", "布団"]`でした…ｽﾔｧ…
