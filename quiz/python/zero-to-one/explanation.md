# 解説

Pythonの知識も問われる問題です。

```python
~1<<1&-~1
```

第1問でも解説した通りチルダ`~`はビット演算のNOTです。
実質的に`~x`は`-(x+1)`です。

```python
>>> print(-~1)
2

>>> print(~1)
-2
```

`<<`はシフト演算です。
2は2進数で10、1ビット左シフトすると100で10進数の4です。

```python
>>> print(-2<<1)
-4
```

`&`は論理積のANDです。
-4は2進数で-0100、2は2進数で0010なのでANDは0000です。

```python
>>> print(-4&2)
0
```

1を使って16といった大きな数値や0を表現できる事を色々試した結果の問題で、答えは`0`なのでした。
