# 解説

```javascript
x = {[[,,]]:[[,,]]}
y = JSON.stringify(x)
console.log(y)
```

このコードの実行結果は `{",":[[null,null]]}` です。

---

## 1. `[,,]` はholeを2つ持つ疎な配列

配列リテラル内のカンマだけが並んだ部分は **hole（空き要素）** になります。末尾のカンマは要素を増やさないため、`[,,]` は **長さ2**・中身が2つのholeの疎な配列（sparse array）です。

```javascript
[,,].length        // => 2
0 in [,,]           // => false （holeなので要素が存在しない）
```

---

## 2. キー側 `[[,,]]` は計算されたプロパティ名

オブジェクトリテラルの `{ [expr]: value }` という記法は **計算されたプロパティ名（computed property name）** です。外側の `[ ]` がその構文で、中身の式は `[,,]` です。

オブジェクトのキーは文字列に変換されるため、配列 `[,,]` が `String([,,])` されます。配列の文字列化は要素を `,` で連結したもので、holeは空文字になります。

```javascript
String([,,])        // => ","  （空 + "," + 空）
```

よってキーは **`","`** になります。

---

## 3. 値側 `[[,,]]` はholeを含む配列を要素に持つ配列

値の `[[,,]]` は計算プロパティではなく、ただの配列リテラルです。長さ1の配列で、その唯一の要素が `[,,]`（長さ2の疎な配列）です。

```javascript
x  // => { ",": [ [ <2 empty items> ] ] }
```

---

## 4. `JSON.stringify` でholeは `null` になる

`JSON.stringify` は配列のholeや `undefined` を **`null`** として出力します。

* 内側の `[,,]` → `[null,null]`
* それを包む配列 → `[[null,null]]`
* キーは `","`

```javascript
JSON.stringify({ ",": [[,,]] })   // => '{",":[[null,null]]}'
```

---

## まとめ

1. `[,,]` は長さ2でholeを2つ持つ疎な配列
2. キー側の `[[,,]]` は計算プロパティ名で、`String([,,])` により `","` というキーになる
3. 値側の `[[,,]]` は疎な配列を1つだけ持つ配列
4. `JSON.stringify` がholeを `null` に変換し、結果は `{",":[[null,null]]}`
