# 解説

```sh
node -e 'console.log(0011 + 0009)'
```

このクイズがなぜ `18` を出力するのか、解説します。

> 注意：このコードは **非strictのスクリプト**（`node -e '...'` や `node ファイル.js`）でのみ動きます。ES module や strict mode では旧式の8進数リテラルが禁止され、`SyntaxError` になります。

---

## 1. 先頭 `0` 付きリテラルは旧式8進数

非strictモードでは、`0` で始まり後ろに数字が続くリテラルは **旧式の8進数（legacy octal）** として扱われます。

### `0011`

```javascript
0011   // 8進数の 11 = 9
```

`0011` は8進数の `11`、つまり `1 × 8 + 1 = 9` です。

### `0009`

```javascript
0009   // 8 進数として無効 → 10 進数の 9
```

`0009` には8進数では使えない数字 `9` が含まれています。この場合は8進数として解釈できず、**10進数の `9`** にフォールバックします（先頭の `0` は無視されて `9`）。

---

## 2. 足し算

```javascript
0011 + 0009   // 9 + 9
```

なので、

```javascript
> 0011 + 0009
18
```

出力は

```text
18
```

となります。同じ「先頭0」でも、含まれる数字によって8進数か10進数かが変わるのが罠です。

---

## まとめ

1. 非strictモードでは先頭 `0` 付きは旧式8進数
2. `0011` は8進数で `9`
3. `0009` は数字 `9` を含むため8進数として無効になり、10進数の `9`
4. `9 + 9 = 18`（strict / module では `SyntaxError`）
