# 解説

```sh
node -e '$=()=>$;console.log(`${$````}`[4])'
```

このクイズがなぜ `$` を出力するのか、ステップごとに解説します。

> 注意：このコードは先頭で `$` にグローバル代入しているため、トップレベルで代入できる **スクリプト実行**（`node -e '...'`）で動かします。

---

## 1. `$` は自分自身を返すアロー関数

```javascript
$ = () => $
```

`$` は「呼ぶと自分自身（`$`）を返す」アロー関数です。

---

## 2. `` $```` `` を読み解く

問題の中身はテンプレートリテラルの補間部に `` $```` `` が入っています。

```javascript
`${ $```` }`
```

`` $`` `` のように関数の直後にバッククォートを書くと **タグ付きテンプレート呼び出し** になります。`` $`` `` は空テンプレートで `$` を呼ぶので、戻り値は `$`（関数）自身です。

```javascript
$``        // → $  （自分自身を返す）
$````      // → ($``)`` → $  （もう一度タグ付けしても結局 $）
```

つまり `` $```` `` の評価結果は、関数 `$` そのものです。

---

## 3. テンプレート内で関数が文字列化される

```javascript
`${ $```` }`   // ${ 関数 $ }
```

テンプレートリテラルの `${...}` の中に関数を置くと、その関数のソース表現に文字列化されます。

```javascript
> `${ () => $ }`
'()=>$'
```

`$` のソースは `() => $` ですが、文字列化されると（環境により空白が詰められて）`'()=>$'` になります。よってテンプレート全体は文字列 `"()=>$"` です。

---

## 4. インデックス4の文字

```text
 (  )  =  >  $
 0  1  2  3  4
```

* 0 が `(`
* 1 が `)`
* 2 が `=`
* 3 が `>`
* **4 が `$`**

したがって、

```javascript
> `${$````}`[4]
'$'
```

出力は

```text
$
```

となります。

---

## まとめ

1. `$ = () => $` は自分自身を返すアロー関数
2. `` $```` `` はタグ付きテンプレート呼び出しだが、結局 `$`（関数）を返す
3. テンプレート `${...}` 内で関数は `"()=>$"` に文字列化される
4. その index 4 がちょうど `'$'`
