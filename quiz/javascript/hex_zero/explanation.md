# 解説

```sh
node -e "console.log(0x0_0-0x0_0)"
```

このクイズがなぜ `0` を出力するのか、解説します。

---

## 1. `0x0_0` は数値リテラル

`0x` で始まるのは16進数リテラルです。さらに JavaScript では、数値リテラルの桁区切りとして **アンダースコア `_`** を使えます（Numeric separators）。

```javascript
0x0_0
```

* `0x` → 16進数
* `0_0` → 区切りを除けば `00`、つまり値は `0`

したがって、

```javascript
> 0x0_0
0
```

`(o_o)` のような顔文字に見えますが、実体はただの `0` です。

---

## 2. 引き算

```javascript
0x0_0 - 0x0_0   // 0 - 0
```

なので、

```javascript
> 0x0_0-0x0_0
0
```

出力は

```text
0
```

となります。

---

## まとめ

1. `0x0_0` は数値区切り `_` 付きの16進数リテラルで、値は `0`
2. `0 - 0` なので結果は `0`
3. 顔文字に見えても、ただの引き算
