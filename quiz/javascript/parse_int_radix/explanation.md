# 解説

```sh
node -e 'console.log(parseInt("256", ~-16).toString(0+11..toString(16)+11000))'
```

このクイズがなぜ `m3` を出力するのか、ステップごとに解説します。

---

## 1. `parseInt("256", ~-16)` で `531`

`~-16` は `15` です（`~x === -(x+1)` なので `~(-16) = 15`）。

```javascript
> parseInt("256", 15)
531
```

基数15で `"256"` を解釈すると、

```text
2 × 15² + 5 × 15 + 6 = 531
```

なので `531` になります。

---

## 2. `toString` の基数を作る `0+11..toString(16)+11000`

ここがこの問題の本体です。順に評価します。

### 2-1. `11..toString(16)`

`11..toString(16)` の `..` は「数値 `11` に対してメソッド呼び出し」です（`11.` が数値、もう一つの `.` がメソッドアクセス）。`11` を16進数表記すると `'b'`。

```javascript
> 11..toString(16)
'b'
```

### 2-2. `0 + 'b'`

数値 `0` と文字列 `'b'` を足すと文字列連結になります。

```javascript
> 0 + 'b'
'0b'
```

### 2-3. `'0b' + 11000`

さらに `+ 11000` も文字列連結になり、

```javascript
> '0b' + 11000
'0b11000'
```

という文字列ができます。

---

## 3. `(531).toString("0b11000")` の基数

`toString` の引数は数値へ変換されます。`"0b11000"` は **2進数リテラル形式** の文字列なので、`Number` で変換すると2進数として読まれます。

```javascript
> Number("0b11000")
24
```

`0b11000` は2進数の `11000` = `24` です。つまり基数24になります。

---

## 4. 24進数で `531` を表記

```javascript
> (531).toString(24)
'm3'
```

`531 = 22 × 24 + 3` で、24進数では `22` が `'m'`、`3` が `'3'` なので `"m3"` です。

出力は

```text
m3
```

となります。

---

## まとめ

1. `parseInt("256", ~-16)` は基数15で `531`
2. `0+11..toString(16)+11000` は文字列連結で `"0b11000"` を作る
3. `toString` の引数として `"0b11000"` は `Number` 変換で2進数 `24` になる
4. `(531).toString(24)` = `"m3"`
