# 解説

```sh
node -e "console.log(10000000000+(0[1]+Math.max)[3]+-1+-0-0)"
```

このクイズがなぜ `1` を出力するのか、ステップごとに解説します。

---

## 1. `(0[1]+Math.max)[3]` で文字 `'e'` を作る

まず `0[1]` を見ます。数値 `0` のプロパティ `1` にアクセスしていますが、そんなプロパティは存在しないので `undefined` です。

```javascript
> 0[1]
undefined
```

次に `Math.max` は関数です。`undefined + Math.max` は片方が文字列化されて連結されます。

```javascript
> 0[1] + Math.max
'undefinedfunction max() { [native code] }'
```

この文字列の先頭を数えると、

```text
 u  n  d  e ...
 0  1  2  3 ...
```

なので、インデックス3は `'e'` です。

```javascript
> (0[1]+Math.max)[3]
'e'
```

ここで `'e'` を作れたことが最大の仕掛けです。

---

## 2. 文字列連結で指数表記の「文字列」を組み立てる

左から順に `+` で連結していきます。先頭の `10000000000` に `'e'` を足した時点で、全体が文字列になります。

```javascript
10000000000 + 'e'        // "10000000000e"
+ -1                     // "10000000000e-1"   (-1 が "-1" として連結)
+ -0                     // "10000000000e-10"  (-0 は "0" として連結)
```

ポイントは `-0` が文字列連結では `"0"` になることです。これにより `"10000000000e-10"` という、指数表記そっくりの文字列が完成します。

```javascript
> 10000000000+(0[1]+Math.max)[3]+-1+-0
'10000000000e-10'
```

---

## 3. 末尾の `- 0` で数値化

最後に `- 0` を行います。`-` は数値演算なので、文字列が数値へ変換されます。

```javascript
> Number("10000000000e-10")
1
```

`10000000000e-10` は `1e10 × 1e-10 = 1` です。

```javascript
> 10000000000+(0[1]+Math.max)[3]+-1+-0-0
1
```

よって出力は

```text
1
```

となります。

---

## まとめ

1. `0[1]` は `undefined`、`Math.max` は関数。連結して `[3]` を取ると文字 `'e'`
2. `'e'` が混ざることで全体が文字列連結になり、`"10000000000e-10"` という指数表記文字列ができる
3. 末尾の `- 0` で数値化され、`1e10 × 1e-10 = 1`
