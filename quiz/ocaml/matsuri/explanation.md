# 解説

```ocaml
"Matsuri"|>fun s->Printf.sprintf"%c%d"s.[0]((String.fold_left(fun n _->n+1)0 s)/2);;
```

このコードの実行結果は `"M3"` です。

## ポイント

`|>` は左辺の値を右辺の関数に渡すパイプ演算子です。つまり `"Matsuri"` が無名関数 `fun s->...` の引数 `s` に渡されます。

`Printf.sprintf "%c%d" 文字 数値` で「1文字」と「整数」を連結した文字列を作っています。

### `%c` の部分 — `s.[0]`

`s.[0]` は文字列の先頭の文字なので、`"Matsuri"` の `'M'` です。

### `%d` の部分 — 文字数 / 2

```ocaml
String.fold_left (fun n _ -> n + 1) 0 s
```

`String.fold_left` は文字列を1文字ずつ畳み込みます。ここでは文字の中身（`_`）を無視し、アキュムレータ `n` を毎回 `+1` しているだけなので、結果は**文字数のカウント**になります。`"Matsuri"` は7文字なので `7` です。

これを `/2` していますが、OCamlの `/` は**整数除算**なので、

```ocaml
7 / 2  (* => 3 *)
```

と切り捨てられて `3` になります。

### 連結

```ocaml
Printf.sprintf "%c%d" 'M' 3  (* => "M3" *)
```

`'M'` と `3` が連結され、最終的な結果は `"M3"` になります。

`String.length s` を使わずに `fold_left` でわざわざ文字数を数え、整数除算の切り捨てで `3` を作り出している点がポイントの問題でした。
