# Java Quine

## M3 Java 8 Quine

Java 8で作成したQuine

昔、WebページにJavaアプレットで実装された電光掲示板が埋め込まれていた時代をイメージして作成しました。
ターミナル上でソースコードが横にスクロールしながら流れ続けます。

### 実行

コンパイルして実行してください。

```sh
javac quine_java8.java
java quine_java8
```

### 解説

ソースコード本体をBase64エンコードした文字列を20行の配列 `a[]` に分割して保持しています。

メインループでは、各行を1文字ずつ左にローテーション（先頭文字を末尾に移動）しながら、各行の同じオフセット位置から97文字を切り出して連結し、フレームごとの表示文字列を構築します。これにより、文字列が横にスクロールしているように見えます。

表示は `c()` メソッドが担当します。蓄積した文字列をBase64デコードし、`printf` でフォーマットすることで、配列 `a[]` の内容（=自身のソースコード）を埋め込んで出力します。`\033[H` でカーソルを左上に戻すことで、スクロールせずに同じ位置を上書き更新します。

出力結果を実行すると、再び同じ出力が得られます（Quineの性質）。
