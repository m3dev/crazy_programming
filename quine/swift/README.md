# Swift Quine

以下2つのQuineを含んでいます。

- M3 Swift Quine
  - Author: [@mfujiwara](https://github.com/mfujiwara)
- M3 Swift Quine: iOSDC Japan 2025 edition
  - Author: [@mfujiwara](https://github.com/mfujiwara)

## 実行

### M3 Swift Quineの実行

```sh
swift quine.swift
```

任意の引数を与えて実行するとアスキーアート部分が「M3T[^m3t]」のQuineに変化します。  
M3T Quineは任意の引数を与えて実行するとアスキーアート部分が「M3」に戻ります。  

```
swift quine.swift -
```

### M3 Swift Quine: iOSDC Japan 2025 editionの実行

```sh
swift quine_iosdc_japan_2025.swift
```

実行するとiOSDC Japan 2025のチャレンジトークンが出現します。
