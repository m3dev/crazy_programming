# Scala Quine

Author: [@vaaaaanquish](https://github.com/vaaaaanquish)

Scalaで作成したQuine。

[技術書典18](https://techbookfest.org/event/tbf18) にて頒布した [エムスリーテックブック８](https://techbookfest.org/product/b94hFWewG7fVRLgqEmSjT1?productVariantID=dWQKDmPPqwY3dfr28X7j4L) に掲載した作品です。

## 実行

scala-cliをインストールします。

```sh
# brew
$ brew install Virtuslab/scala-cli/scala-cli

# sh
$ curl -sSLf https://scala-cli.virtuslab.org/get | sh
```

scala-cliでquineを実行します。

```sh
scala-cli run quine.scala
```
